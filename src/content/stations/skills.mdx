## One ability at a time

Every skill gets shown alone first. Once the agent is running, success and failure blur together.

A skill has three parts:

1. A **name** the model can read
2. **Parameters**, whatever has to be decided per call
3. A **description** in plain language

That description is not documentation for humans. It is the interface the model reads when it
picks a skill.

```json
{
  "name": "wave",
  "description": "Wave at a person in view. Use when someone greets the robot.",
  "parameters": {
    "arm": { "type": "string", "enum": ["left", "right"] },
    "duration_s": { "type": "number", "default": 2 }
  }
}
```

**Function calling** is the mechanism. The model moves nothing itself. It emits "call `wave` with
these values" and our software runs it.

## Why this framing matters

- Every skill on this page is written by hand, tested by hand, safe by construction
- Station 5 adds no new abilities
- What it adds is the choice: which skill, when, with which parameters, without anyone writing that
  decision down beforehand
