## A skill is a function the model may call

```python
def wave(arm: str = "right", times: int = 1) -> str:
    """Wave at a person in view. Use when someone greets the robot."""
    robot.play_action("wave", side=arm, times=times)
    return "waved"
```

The docstring is the whole interface. It is what the model reads when it decides.

> watch the same call get refused.
