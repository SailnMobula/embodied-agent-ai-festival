<SkillCatalogue />

- Ask in plain words: two metres straight, a step to the left
- It refuses to move when someone stands too close

## A skill is a function the model may call

```json
{
  "name": "wave",
  "description": "Wave at a person in view. Use when someone greets Marvin.",
  "kind": "action",
  "target": "wave"
}
```

The description is the whole interface. It is what the model reads when it decides.

> **Live demo: fire a skill without the model.** Test `wave` in the panel. Then stand too close and
> watch the same call get refused.
