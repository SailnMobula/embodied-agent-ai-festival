## A brain in a sealed jar

Think back to your first question to ChatGPT. Someone asked it for today's weather, and it
answered. Confidently. Out of a frozen snapshot of the web.

- The newest, largest model hits the same wall today
- The answer was never inside it
- No window to the world, no hands to reach through

So the question is not how to build a smarter brain. It is what we add to the jar.

## What we add

<AgentArchitecture />

- **Memory**: the brain forgets everything the moment you hit send
- **Skills**: a door in the jar, a camera to look through, an arm to move
- **Reasoning**: turning "find someone and wave" into steps

An LLM with memory, reasoning and skills around it. That bundle is the agent, and **skill** is the
word that carries through every station today.

> **Live demo: switch to the terminal.** Ask a small local model for the weather in Kassel and
> watch it invent an answer. The fix was never a better model, it was a door.

```bash
ollama run qwen2.5:0.5b "what is the weather in Kassel right now?"
```

## Skills you already know

| Skill in the web and PC world | Skill in the embodied world                    |
| ----------------------------- | ---------------------------------------------- |
| Read a file                   | Look through the camera and name what is there |
| Search the web                | Walk to a different room and scan it           |
| Write a file                  | Pick up an object and put it somewhere else    |
| Call an API                   | Wave, point, hand something over               |

The pattern is identical. Only the consequences differ: a wrong file write is undone with one
command, a wrong arm movement is not.
